# Autonomous AI Treasure Hunt Agent

An AI agent that uses BFS (Breadth-First Search) pathfinding
to find treasure while avoiding traps on a 10x10 grid.

## Install & Run

pip install -r requirements.txt
python main.py

## How it works

- Blue = AI player
- Gold = Treasure
- Red = Traps
- AI uses BFS to find the safest path to treasure
